Purpose

This protocol defines the sequence for field documentation. It applies to photography, video, audio, transcription, metadata capture, storage and review.

This protocol is drafted. It becomes implemented after named personnel, secure storage, consent records and review logs are in service.

Pre-field gate

  1. Activity purpose recorded.
  2. Individual, practitioner, community and site authority needs identified.
  3. Consent brief delivered before the visit.
  4. Compensation or reciprocity terms recorded.
  5. Approved media types listed.
  6. Prohibited media types listed.
  7. Archive access tier default set to restricted.
  8. Storage location prepared.
  9. Withdrawal contact path provided.
  10. Review dates assigned.

If one item is incomplete, field documentation is postponed or limited to non-recorded conversation.

Public release gate

The communications owner may publish only after the archive steward confirms active consent status, all applicable authority approvals, public access tier, separate public copy, approved text or media, location permission, valid review date, withdrawal path and access log entry.

Incident response

  1. Stop capture.
  2. Mark affected files restricted or sealed.
  3. Notify field lead and archive steward.
  4. Record incident timestamp, material IDs and authority affected.
  5. Decide delete, seal, restrict, revise or continue.
  6. Log final action and next review date.

Studium does not operate an apprenticeship program, steward network or institutional partnership structure.
